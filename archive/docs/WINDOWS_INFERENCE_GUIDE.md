# Mars Object Detection - Windows Inference Guide

## Quick Start

### Step 1: Install Dependencies

Run the automated setup script:

```cmd
setup_windows_env.bat
```

Or manually install:

```cmd
pip install ultralytics opencv-python Pillow numpy
```

### Step 2: Reconstruct Test Images

The FPGA payload contains 50 test images in binary format. Convert them back to JPG:

```cmd
python reconstruct_test_images.py
```

**Output:**
- `test_images_reconstructed/` - 50 test images (256×256 JPG)
- `test_labels_reconstructed/` - Ground truth labels (YOLO format)

### Step 3: Verify Model

Run inference on all 50 test images and print statistics:

```cmd
python verify_model.py
```

**Expected output:**
- Total detections count
- Detections per class (Soil, Bedrock, Sand, Big Rock)
- Sample detection details

### Step 4: Live Visualization (Requires OpenCV)

Launch the interactive viewer:

```cmd
python live_inference_windows.py
```

**Controls:**
- `D` - Next image
- `A` - Previous image
- `Q` - Quit

**Display:**
- Left panel: Ground truth labels
- Right panel: Model predictions with confidence scores

## Troubleshooting

### Python Not Found
Install Python 3.8+ from python.org

### Package Installation Fails
Use conda environment:
```cmd
conda create -n mars python=3.11
conda activate mars
pip install -r requirements.txt
```

### Model File Missing
Ensure `fpga_payload/best.pt` exists (6 MB file).
This is the trained model from Mac.

### No Test Images
Run `python reconstruct_test_images.py` first to generate test images from binary files.

### OpenCV Import Error
If opencv-python conflicts with other packages:
```cmd
pip uninstall opencv-python opencv-contrib-python
pip install opencv-python
```

### Slow Inference
Inference runs on CPU by default. Expected speed: ~50-100ms per image on modern CPU.

## Next Steps After Verification

### 1. Port Complete Dataset to Windows (Optional)

If you want to run inference on all 443 test images (not just the 50 in fpga_payload):

**From Mac:**
```bash
cd ~/Documents/mars_object_detection
tar -czf yolo_mars_test.tar.gz data/yolo_mars/images/test data/yolo_mars/labels/test
```

**Transfer to Windows** via:
- External drive
- Cloud storage (OneDrive, Google Drive)
- Network share

**On Windows:**
```cmd
tar -xzf yolo_mars_test.tar.gz
```

Then update `live_inference_windows.py` paths:
```python
TEST_IMAGES_DIR = "data/yolo_mars/images/test"
TEST_LABELS_DIR = "data/yolo_mars/labels/test"
```

### 2. Deploy to PolarFire FPGA

Once model is verified on Windows:

1. Transfer VNNX binary (from WSL compilation):
   ```
   ~/build_temp/mars_yolov8.vnnx (7.4 MB)
   ```

2. Transfer to PolarFire via:
   - UART bootloader
   - SD card
   - JTAG debugger
   - Network (if available)

3. Run VectorBlox inference on hardware:
   ```c
   // Pseudo-code for PolarFire firmware
   vbx_model_load("mars_yolov8.vnnx");
   vbx_inference(input_image_buffer, output_buffer);
   parse_yolo_output(output_buffer, detections);
   ```

## Success Criteria

Before deploying to FPGA, verify:

- [ ] Model loads without errors
- [ ] Inference completes in < 200ms per image (CPU)
- [ ] Detections align with ground truth visually
- [ ] Soil/Bedrock classes have reasonable accuracy
- [ ] No crashes or memory errors during batch processing

Once verified, proceed to PolarFire deployment with confidence.
